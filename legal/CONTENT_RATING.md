# Content rating answers: Human Cannonball: Wedding Edition

Use these when a portal or rating questionnaire (IARC, Google, CrazyGames, Poki) asks about the game's content.

| Question | Answer |
| --- | --- |
| Violence | **Mild cartoon / slapstick.** A cartoon character is fired from a cannon and bumps into objects and other cartoon characters, who fall over comically. No blood, gore, injury detail, weapons used against people, or death. |
| Blood / gore | No |
| Fear / horror | No |
| Sexual content or nudity | No |
| Strong language | No. Mild Hinglish exclamations only ("Arre!", "Haaye!", "Oye hoye!"). |
| Drugs, alcohol, tobacco | No |
| Gambling or simulated gambling | No |
| Discrimination / hate | No. The wedding guests are affectionate, generic cartoon types, with no caricatures of any community. |
| Religious content | No. Secular party décor only: lights, flowers, balloons, chandeliers, fireworks. |
| User-generated content, chat, user interaction | No |
| Shares location / personal info | No |
| In-app purchases / real-money items | No |
| Ads | Only on CrazyGames and Poki (shown by the platform between levels, plus opt-in rewarded ads). None on the website, itch.io or YouTube. |
| Digital purchases / loot boxes | No |
| Data collection | None by the game (see `PRIVACY_POLICY.md`) |
| Target audience | **All ages.** Designed for casual players aged 10 and up, and suitable for younger players. Not specifically directed at children under 13. |

**Expected ratings:** PEGI 3 or PEGI 7 (mild cartoon violence) · ESRB Everyone · IARC 3+/7+ · Google Play "Everyone".
